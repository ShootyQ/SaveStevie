# Chapter paper backgrounds

Four original, individually generated paper illustrations for Save Stevie.
Each uses a light, quiet playfield with hand-drawn pencil or crayon decoration
at the edges: notebook doodles, a corrected graph-paper quiz, crayon sketchbook
paper, and worn detention homework. Full PNG artwork is preserved.

The arena uses the complete PNG as a CSS nine-slice paper layer behind the
transparent combat canvas. Corners use 18% source slices and 80–112px display
widths; edges and the quiet middle stretch to fill the arena. The paper begins
58px below the HUD so top decorations stay visible. No art is cropped away with
cover sizing, and no background image is repainted by the game loop.
Chapter selection updates the layer with deployment versioning. The layer's
faint procedural grid and the panel paper provide a missing-image fallback.
