# Chapter paper backgrounds

Four original, individually generated paper illustrations for Save Stevie.
Each uses a light, quiet playfield with hand-drawn pencil or crayon decoration
at the edges: notebook doodles, a corrected graph-paper quiz, crayon sketchbook
paper, and worn detention homework. Full PNG artwork is preserved.

The arena displays these as centered, covering CSS backgrounds, so outer
corners may be cropped on narrow phones or landscape views. Assets are loaded
when their chapter is selected, with deployment versioning. Faint procedural
paper/grid layers underneath provide a fallback; no background image is drawn
on every canvas frame. Chapter selection lives in js/chapters.js.
