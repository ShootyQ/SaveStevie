All exports match the listed upload dimensions. Artwork PNGs are opaque RGB; Library Logo is an RGBA PNG with a transparent background. App Icon is an RGB JPG. Each composition was generated separately; the small capsule limits the cast to Stevie and the red grunt for readability. Header, Main and Vertical also feature Basil, King Doodle, Zoom Nugget and the armored tank. Page Background is deliberately dark and quiet through the center. Shortcut Icon uses a close-up of Stevie and his pencil; Steam accepts the PNG and generates its ICO. Final export sizing makes only the tiny aspect-ratio adjustment needed to fit the supplied dimensions.

Generated with OpenAI image generation, using existing game art as references. Rough handmade styling describes the appearance, not the production method.

See [the full Steam asset checklist](../../docs/steam-assets.md) for remaining assets. Screenshots remain deferred.

## Library and event notes

- Library Header Capsule intentionally reuses the approved Store Header Capsule.
- App Icon reuses Stevie’s Shortcut Icon artwork, resized and encoded as the required JPG.
- Library Capsule is a separate 2:3 portrait composition, not a stretched Store Vertical Capsule.
- Library Hero contains artwork only, with quiet space on the left for the separate logo. Its generated master is 2206 × 713 px, upscaled to the required 3840 × 1240 export.
- Library Logo contains only the game wordmark with verified real alpha transparency. Upload it separately from the Hero.
- Event Cover is reusable generic promotional artwork with “Draw. Defend. Survive.”, without a date or release claim. Event Header uses the logo and artwork. Customize these for a specific future announcement and check Steam’s clipping preview when uploading.
- Screenshots remain deferred. Bundle assets are conditional on setting up a bundle and are not included.
